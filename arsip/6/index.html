Membuat & Mempublish Website GRATIS Menggunakan Platform GitHub

Pelajari cara membuat website sederhana menggunakan Visual Studio Code, mempublikasikannya secara gratis melalui GitHub, mendapatkan alamat website online, serta membuat website interaktif dengan bantuan GPT.

VS Code HTML GitHub GitHub Pages GPT
Lihat Materi yang Dipelajari
  1. Membuat website sederhana menggunakan Visual Studio Code (VS Code) . VS Code dapat di-download gratis di website resmi Visual Studio Code .
  2. Membuat website sederhana secara langsung menggunakan VS Code .
  3. Mempublish website sehingga dapat digunakan secara online menggunakan platform GitHub . Pada bagian ini juga dipraktikkan cara mengubah branch main menjadi branch master .
  4. Mendapatkan alamat website dari GitHub sehingga website dapat diakses secara online dan gratis.
  5. Praktek membuat website dengan bantuan GPT sehingga tampilannya menjadi menarik, menggunakan contoh website kuis pengetahuan umum interaktif sebanyak 10 soal.

Menggunakan Platform Git dan GitHub untuk Membuat & Mempublish Website secara GRATIS

Praktek membuat website sederhana menggunakan Visual Studio Code, menggunakan Git untuk mempublish file website ke GitHub, memperoleh alamat website yang dapat diakses online secara gratis, serta membuat contoh website interaktif dengan bantuan GPT.

Git GitHub VS Code HTML GPT
Lihat Materi yang Dipelajari
  1. Menyiapkan dan menggunakan Visual Studio Code (VS Code) untuk membuat website sederhana. VS Code dapat di-download gratis melalui website resmi Visual Studio Code .
  2. Membuat website sederhana secara langsung di VS Code menggunakan file HTML.
  3. Menggunakan Git untuk mempublish file website ke platform GitHub sehingga website dapat digunakan secara online. Git untuk Windows dapat di-download melalui website resmi Git .
  4. Membuat akun GitHub dan mendapatkan alamat website dari GitHub sehingga dapat diakses secara online secara gratis. Akun GitHub dapat dibuat melalui halaman pendaftaran GitHub .
  5. Praktek membuat website dengan bantuan GPT agar tampilannya lebih menarik, menggunakan contoh kuis pengetahuan umum interaktif sebanyak 10 soal seperti pada contoh website kuis ini .
